EV424 ENTRY 000182

Public Source Reproducible Verify Gate

QR: scan to open this public command guide.

EV424|TYPE=RECEIPT|NO=000182|SHA12=41D23E925F09|GATE=PUBLIC_SOURCE_REPRODUCIBLE_VERIFY

TYPE: RECEIPT

OBJECT: debian-reference.en.pdf

SOURCE: Debian official public PDF URL

EXPECTED SHA256:

af0239b8206536706af95dbe55ec8259c3595617c74dea7d9be7101ebe9cc963

SHA12: 41D23E925F09

목차명령어

아래 명령어를 Linux/Unix 터미널에 그대로 붙여넣으면 공개 원천에서 PDF를 다운로드하고, SHA256 검증 후 EV424 공개 재현 검증 게이트 PASS 라벨을 표시합니다.

/usr/bin/env -C '/tmp' /bin/sh -c "/usr/bin/curl -fL -o 'debian-reference.en.pdf' 'https://www.debian.org/doc/manuals/debian-reference/debian-reference.en.pdf' && /usr/bin/printf '%s  %s\n' 'af0239b8206536706af95dbe55ec8259c3595617c74dea7d9be7101ebe9cc963' 'debian-reference.en.pdf' | /usr/bin/sha256sum -c - && /usr/bin/printf '\033[34m%s\033[97m%s\033[32m%s\033[0m\n' 'EV424' '_PUBLIC_SOURCE_REPRODUCIBLE_VERIFY_GATE=' 'PASS'"

기대 출력

debian-reference.en.pdf: OK
EV424_PUBLIC_SOURCE_REPRODUCIBLE_VERIFY_GATE=
PASS

Linux/GNU tool result: OK

EV424 gate result: PASS

OK는 Linux/GNU sha256sum 원검증 결과이고, PASS는 EV424 공개 원천 재현 검증 게이트 판정입니다.
