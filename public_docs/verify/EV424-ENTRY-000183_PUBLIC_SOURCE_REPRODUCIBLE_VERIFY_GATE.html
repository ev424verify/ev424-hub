Command guide

Paste the command below into a Linux/Unix terminal. It downloads the public source PDF, verifies the SHA256 checksum, then prints the EV424 public reproducible verify gate PASS label.

/usr/bin/env -C '/tmp' /bin/sh -c "/usr/bin/curl -fL -o 'NIST.AI.100-4.pdf' 'https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-4.pdf' && /usr/bin/printf '%s  %s\n' 'a387a4977db70d65cdbc178c8b0cb8aa5dedb85fa80d6f473c244e2767a4fd54' 'NIST.AI.100-4.pdf' | /usr/bin/sha256sum -c - && /usr/bin/printf '\033[34m%s\033[97m%s\033[0m\n\033[32m%s\033[0m\n' 'EV424' '_PUBLIC_SOURCE_REPRODUCIBLE_VERIFY_GATE=' 'PASS'"
